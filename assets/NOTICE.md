# Sources and asset licenses

## Laboratory source

The primary academic source is the user's corrected CSST106 Laboratory Activity 7 Word handout, titled "Segmentation Technique", Week 13, first semester, AY 2026–2027. The website includes only Lab 7. It does not reproduce any college logo. The generic VisionLab SVG mark is shared with the existing laboratory compilation projects.

The four files in `python/` and the four original result figures in `assets/results/part*.png` are preserved from the completed local laboratory. The original Part 4 uses DeepLabV3 ResNet50. Its 9.46% cat pixel coverage is not an accuracy measure. Classical IoU values are foreground overlap on the synthetic images, not instance-separation scores.

## Model

`assets/models/deeplabv3-mobilenetv3.onnx` is an FP32 ONNX export of TorchVision's DeepLabV3 MobileNetV3 Large, using official COCO_WITH_VOC_LABELS_V1 weights. It has not been trained or fine-tuned for this website. The weights use the 20 Pascal VOC object categories plus background from a COCO subset. Official documentation: https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.segmentation.deeplabv3_mobilenet_v3_large.html . Official checkpoint: https://download.pytorch.org/models/deeplabv3_mobilenet_v3_large-fc3c493d.pth . TorchVision's BSD license is preserved in `models/TORCHVISION-LICENSE.txt`. Source data rights remain with their owners; software licensing does not imply ownership of training images.

The MobileNetV3 and original ResNet50 backbones have different predictions and preprocessing. Browser results are labeled separately from original desktop results. The export has dynamic spatial dimensions, opset 17, RGB ImageNet normalization, and no auxiliary output. `models/manifest.json` contains the SHA-256 hash and exact byte count. The reference script and numerical parity evidence document the conversion.
